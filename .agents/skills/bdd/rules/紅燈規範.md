# Rule 1 - 紅燈只寫測試程式

- `red` 階段必須只修改目標情境需要的 step definition、World 或必要測試支撐。
- `red` 階段不得寫入產品行為。
- `red` 階段必須只實作本輪情境用到的步驟，不得為後面的情境預先寫 step definition。
- 跨步驟狀態必須放在該情境自己的 World 或 scenario-scoped 物件，不得使用模組層級可寫狀態。

## Good Example

- 只補上目標情境的測試程式，沒有偷寫產品邏輯。

```javascript
Given("房間 {string} 內已有玩家 {string}", function (roomId, playerId) {
  this.rooms.seedPlayer(roomId, playerId);
});

When("玩家 {string} 送出聊天訊息 {string}", async function (playerId, message) {
  this.lastResponse = await this.chatClient.send(playerId, message);
});
```

## Bad Example

- 在 step definition 內直接實作產品行為，已越過紅燈邊界。

```javascript
When("玩家 {string} 送出聊天訊息 {string}", function (playerId, message) {
  this.messages.push({ playerId, message });
  this.lastResponse = { ok: true };
});
```

# Rule 2 - 紅燈必須接線到產品邊界

- step definition 必須使用 Cucumber Expression，不得在同一個表達式混用正則。
- `假設` 必須直接建立句子描述的前置狀態，不得呼叫本輪 `當` 所驗證的動作來湊出狀態。
- `當` 必須呼叫目標情境鎖定的產品邊界，例如 domain service、HTTP client 或 browser driver。
- `那麼` 必須斷言句子已點名的可觀察輸出，不得把產品行為寫進 step definition。
- 重複的操作應該抽成一般函式，不得從一個 step definition 再呼叫另一句 Gherkin。

## Good Example

- `假設` 建立狀態，`當` 接線到產品邊界，`那麼` 只檢查可觀察結果。

```javascript
When("玩家 {string} 送出聊天訊息 {string}", async function (playerId, message) {
  this.lastResponse = await this.chatClient.send(playerId, message);
});

Then("玩家 {string} 應該看到聊天訊息 {string}", function (playerId, message) {
  assert.equal(this.chatView.lastMessageFor(playerId), message);
});
```

## Bad Example

- `當` 沒有接到產品邊界，而是在測試碼裡自己完成行為。

```javascript
When("玩家 {string} 送出聊天訊息 {string}", function (_playerId, message) {
  this.chatView.messages.push(message);
  this.lastResponse = { ok: true };
});
```

# Rule 3 - 紅燈結果必須是有效失敗

- 寫完 `red` 後執行結果必須失敗，且失敗原因必須是斷言失敗，或產品邊界因為行為尚未實作而失敗。
- `Undefined step`、`Ambiguous step`、`Gherkin parse error`、`exitCode` 為 `null`、`timedOut` 為 `true` 都不得當作有效紅燈。
- 行為原本就存在而測試直接通過時，必須把該情境視為已通過，不得刪除產品程式來製造紅燈。
- 紅燈證據不合格時，必須先修正測試程式或命令，不得進入 `green`。

## Good Example

- 紅燈來自尚未完成的行為，屬於正確失敗。

```json
{
  "executed": true,
  "exitCode": 1,
  "timedOut": false,
  "stderr": "",
  "stdout": "AssertionError: expected latest chat message to equal \"哈囉\""
}
```

## Bad Example

- 失敗原因來自未定義步驟，這還不是可接受的紅燈。

```json
{
  "executed": true,
  "exitCode": 1,
  "timedOut": false,
  "stderr": "Undefined. Implement with the following snippet..."
}
```
