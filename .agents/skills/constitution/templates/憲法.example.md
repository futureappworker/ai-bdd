# 功能規格憲法

- Skill: specify
- 產出: `specs/<feature>/spec.md`

# Rule 1 - I. 規格敘述使用繁體中文

- 部位必須是功能需求的敘述文字。
- 這些敘述文字必須使用繁體中文。
- 此規則確保規格敘述以同一種語言撰寫。

## Good Example

- 同一則功能需求的敘述使用繁體中文，編號保留 `FR-US1-001`。

```markdown
- **FR-US1-001**: 使用者可以建立新相簿並看到相簿名稱。
```

## Bad Example

- 同一則功能需求的敘述只有英文。

```markdown
- **FR-US1-001**: User can create a new album and see the album name.
```
