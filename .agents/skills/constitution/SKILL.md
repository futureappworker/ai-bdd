# SOP

## Phase 1: 讀取需求

1. Read 讀取使用者輸入並取得使用者描述、已點名的 Skill、部位、必備或禁止內容、已提供的訪談答案，以及使用者提到的產出線索。
2. Think 整理使用者描述、已點名的 Skill、部位、必備或禁止內容與產出線索。

## Phase 2: 判斷寫入目標

1. Read [寫入目標判斷規範](rules/寫入目標判斷規範.md)並取得必要憲法與產出憲法的採用條件。
2. Think 依已載入規範決定本次寫入目標；寫入目標是必要憲法時，同時決定產出路徑。

## Phase 3: 判斷產出憲法的 Skill 與產出

1. Read 當寫入目標是產出憲法時，讀取 [Skill 與產出判斷規範](rules/Skill與產出判斷規範.md)並取得候選比對、唯一採用與留空條件。
2. Read 當寫入目標是產出憲法時，依已載入規範讀取 `.agents/skills/` 底下各 Skill 的 `SKILL.md`，取得 description 與寫入步驟。
3. Think 當寫入目標是產出憲法時，依已載入規範決定目標 Skill 與產出檔名；無法唯一決定時，該項為空。

## Phase 4: 推理產出憲法路徑

1. Read 當寫入目標是產出憲法且產出檔名已決定時，讀取 [產出路徑推理規範](rules/產出路徑推理規範.md)並取得推理來源、採用條件與禁止沿用檔名的要求。
2. Read 當寫入目標是產出憲法且產出檔名已決定時，依已載入規範讀取 `.agents/skills/` 中對該產出檔名的專案路徑引用，取得候選路徑。
3. Think 當寫入目標是產出憲法時，依已載入規範決定本次憲法檔頭的產出路徑；無法決定時，產出路徑為空。

## Phase 5: 決定寫入動作

1. Read 當寫入目標是必要憲法時，讀取 `constitution/共同/憲法套用規範.md`；該檔不存在時取得尚無必要憲法。
2. Read 當寫入目標是產出憲法且目標 Skill 與產出檔名都已取得時，讀取 `constitution/<skill>/<artifact>.md`；該檔不存在時取得尚無這份產出憲法。
3. Read [必要憲法寫入規範](rules/必要憲法寫入規範.md)並取得基本版與增量的採用條件。
4. Think 依已載入規範決定寫入動作是基本版或增量。
5. Think 列出既有 Rule；檔案不存在時，既有 Rule 為空。

## Phase 6: 判斷增量內容

1. Read 當寫入動作是增量時，讀取 [部位與內容判斷規範](rules/部位與內容判斷規範.md)並取得部位收斂、內容採用與留空條件。
2. Think 當寫入動作是增量時，依已載入規範決定本次部位與必備或禁止內容；無法唯一決定時，該項為空。

## Phase 7: 訪談下一個必要缺口

1. Read 當寫入動作是增量時，讀取 [憲法訪談規範](rules/憲法訪談規範.md)並取得缺口判斷與提問範圍。
2. Think 依已載入規範決定下一個必要問題；沒有缺口時，問題為空。
3. Write 當問題不是空的，將這一個問題寫入回覆。
4. Think 當問題不是空的，決定本次流程停止於訪談問題。

## Phase 8: 撰寫憲法

1. Read [憲法模組規範](rules/憲法模組規範.md)並取得增量範圍、部位與拒絕寫入條件。
2. Think 依已載入規範決定本次要寫入的內容與目標路徑；已載入規範要求拒絕時，決定不寫入。
3. Write 當決定不寫入時，將衝突或拒絕原因寫入回覆。
4. Think 當決定不寫入時，決定本次流程停止於拒絕原因。
5. Read 當寫入動作是基本版時，讀取 [憲法套用規範骨架](templates/憲法套用規範.md)並取得固定內容結構。
6. Read 當寫入動作是基本版時，讀取 [憲法套用規範範例](templates/憲法套用規範.example.md)並取得完整基本版。
7. Write 當寫入動作是基本版時，依已載入規範與已載入樣板與範例，將基本版寫入 `constitution/共同/憲法套用規範.md`。
8. Read 當寫入動作是增量且決定寫入時，讀取 [憲法骨架](templates/憲法.md)並取得固定內容結構。
9. Read 當寫入動作是增量且決定寫入時，讀取 [憲法範例](templates/憲法.example.md)並取得完整使用方式。
10. Write 當寫入動作是增量且決定寫入時，依已載入規範與已載入樣板與範例，將這一條已確認的 Rule 寫入目標憲法檔。

## Phase 9: 檢查憲法

1. Read 依已載入規範與已載入樣板與範例檢查本次寫入的憲法檔，並列出不符合項目。

## Phase 10: 修正憲法

1. Write 修正本次寫入的憲法檔中可由既有資訊處理的全部不符合項目。
