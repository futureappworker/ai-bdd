# Rule 1 - 檔案不存在時寫入基本版

- 寫入目標是必要憲法，且 `constitution/共同/憲法套用規範.md` 不存在時，寫入動作必須是基本版。
- 基本版必須一次寫入 `constitution/共同/憲法套用規範.md`。
- 基本版內容必須採用憲法套用規範範例的完整憲法，不得保留占位符。
- 基本版的問題必須為空。
- 不得為了產生基本版而詢問 Skill、產出路徑、部位、必備內容或禁止內容。

## Good Example

- 必要憲法檔不存在，因此直接寫入範例中的完整基本版，回覆沒有提問。

```text
寫入動作: 基本版
問題:
寫入: constitution/共同/憲法套用規範.md
```

## Bad Example

- 同一則必要憲法檔不存在，卻先詢問要約束哪一個 Skill。

```markdown
補 Skill：這條憲法要約束哪一個 Skill？
```

# Rule 2 - 非基本版必須增量

- 必要憲法檔已存在時，寫入動作必須是增量。
- 寫入目標是產出憲法時，寫入動作必須是增量。
- 必要憲法的增量必須只修改使用者確認的那一條 Rule。
- 必要憲法的增量不得改寫適用範圍檔頭。

## Good Example

- 必要憲法檔已存在，使用者確認修改 Rule 2，因此適用範圍維持原句。

```markdown
- 適用：寫入憲法產出的 Skill
```

## Bad Example

- 同一則已存在的必要憲法，使用者確認修改 Rule 2，增量卻改寫適用範圍。

```markdown
- 適用：全部 Skill 與原始碼
```

# Rule 3 - 基本版對照範例檢查

- 檢查基本版時，必須對照憲法套用規範的骨架與範例。
- 不得因基本版含有多條 Rule，或條文沒有寫「部位必須是」，而判定基本版不符合。

## Good Example

- 基本版含有範例中的四條 Rule，檢查結果是符合。

```text
不符合項目:
```

## Bad Example

- 同一份含有四條 Rule 的基本版，因為不是單條增量而被判定不符合。

```text
不符合項目: 本次寫入了多條 Rule
```
