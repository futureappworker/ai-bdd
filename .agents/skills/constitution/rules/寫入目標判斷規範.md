# Rule 1 - 指向必要憲法時必須採用

- 描述點名 `constitution/共同/憲法套用規範.md` 時，寫入目標必須是必要憲法。
- 描述出現「必要憲法」、「共同憲法」、「共用憲法」或「共同套用」時，寫入目標必須是必要憲法。
- 描述同時出現「憲法」與「共用」，且沒有點名其他 Skill 時，寫入目標必須是必要憲法。
- 必要憲法的產出路徑必須是 `constitution/共同/憲法套用規範.md`。
- 寫入目標是必要憲法時，不得改判成某個 Skill 的產出憲法。

## Good Example

- 「幫我產生 共用 的憲法」同時出現憲法與共用，因此寫入目標是必要憲法，路徑是共同套用檔。

```text
寫入目標: 必要憲法
產出路徑: constitution/共同/憲法套用規範.md
```

## Bad Example

- 同一則「幫我產生 共用 的憲法」沒有採用必要憲法，寫入目標被留空。

```text
寫入目標:
產出路徑:
```

# Rule 2 - 未指向必要憲法時採用產出憲法

- 沒有採用必要憲法時，寫入目標必須是產出憲法。
- 產出憲法的目標 Skill、產出檔名與產出路徑必須留給後續步驟決定。

## Good Example

- 「查詢 API 要有分頁」沒有指向必要憲法，因此寫入目標是產出憲法。

```text
寫入目標: 產出憲法
```

## Bad Example

- 同一則「查詢 API 要有分頁」被改判成必要憲法。

```text
寫入目標: 必要憲法
產出路徑: constitution/共同/憲法套用規範.md
```
