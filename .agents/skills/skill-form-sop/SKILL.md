# SOP

## Phase 1: 撰寫 SOP

1. Read [SOP 格式規範](rules/sop-格式規範.md)並取得結構要求。
2. Read [SOP 品質把關規範](rules/sop-品質把關規範.md)並取得內容要求。
3. Read [SOP 精簡與按需載入規範](rules/sop-精簡與按需載入.md)並取得精簡與載入要求。
4. Write 依需求與已載入規範撰寫或修改目標 Skill 的 `SKILL.md` 中的 SOP。

## Phase 2: 檢查 SOP

1. Read 依已載入規範逐條檢查目標 Skill 的 `SKILL.md` 中的 SOP 並列出不符合項目。

## Phase 3: 修正 SOP

1. Write 修正目標 Skill 的 `SKILL.md` 中 SOP 的全部不符合項目，使 SOP 符合已載入規範。
