# Rule 1 - 背景只放全數情境都成立的假設

- 功能 `背景` 的每個步驟必須對該檔每一個場景都成立。
- Rule `背景` 的每個步驟必須對該 Rule 底下每一個場景都成立，而且不得重複已經放在功能 `背景` 的步驟。
- 只有部分場景成立的前置必須留在那些場景裡。
- `背景` 只能放 `假設`，以及接在 `假設` 後面的 `而且`。`背景` 不得包含 `當` 或 `那麼`。
- `背景` 的步驟行不得超過 4 行。註解與 Data Table 的列不計入這 4 行。
- 超過 4 行的共用前置必須收成一個較高的 `假設`。這個句子必須已在 DSL 寫明它依序沿用哪些既有句子。
- 會隨 `例子` 換值的資料不得寫死在 `背景`。

## Good Example

- 每個結帳場景都從空購物車開始，但只有部分場景先放入商品，所以放商品留在場景裡。

```gherkin
功能: 結帳

  背景:
    假設 沒有訂單且購物車是空的

  Rule: 只有購物車有商品且地區可配送時才能建立訂單

    場景: EC-2.1 空購物車、配送地區台北市
      當 "會員A" 以配送地區 "台北市" 結帳

    場景: EC-2.3 購物車有 SKU-1001 兩件、配送地區台北市
      # 商品編號="SKU-1001"
      # 數量="2"
      假設 購物車已有商品
      當 "會員A" 以配送地區 "台北市" 結帳
```

## Bad Example

- 功能背景寫入「購物車已有商品」，套到空購物車的場景後，那個場景的起點是錯的。

```gherkin
功能: 結帳

  背景:
    假設 沒有訂單且購物車是空的
    而且 購物車已有商品

  Rule: 只有購物車有商品且地區可配送時才能建立訂單

    場景: EC-2.1 空購物車、配送地區台北市
      當 "會員A" 以配送地區 "台北市" 結帳
```

# Rule 2 - 同一串步驟換值必須用場景大綱

- 同一串步驟只換值，而且每一組值都要單獨執行時，必須使用 `場景大綱` 與 `例子`。
- `例子` 至少必須有兩列資料。只有一列時，必須改回 `場景`，把值直接寫進行列。
- `<欄名>` 必須出現在該大綱的 `例子` 表頭，而且與表頭文字完全相同。
- 字串參數的雙引號必須寫在步驟上。整數參數在步驟中不得加引號。`例子` 儲存格與 Data Table 儲存格不得加引號。
- 一個步驟要一次收下一批資料時，必須使用 Data Table，不得把那張表寫成 `場景大綱`。

## Good Example

- 三組代碼各跑一次，引號在步驟上，儲存格沒有引號。

```gherkin
    場景大綱: EC-1.1 有庫存的商品與數量
      當 "會員A" 把商品 "<商品編號>" 加入購物車 <數量> 件
      那麼 "會員A" 看到的購物車應該符合
        | 商品編號 | 數量 |
        | <商品編號> | <數量> |

      例子:
        | 商品編號 | 庫存 | 數量 |
        | SKU-1001 | 10 | 2 |
        | SKU-0042 | 8 | 3 |
```

## Bad Example

- 兩組商品各寫成一個場景，同一串步驟沒有收成場景大綱。

```gherkin
    場景: EC-1.1 有庫存的 SKU-1001
      當 "會員A" 把商品 "SKU-1001" 加入購物車 2 件

    場景: EC-1.1 有庫存的 SKU-0042
      當 "會員A" 把商品 "SKU-0042" 加入購物車 3 件
```

# Rule 3 - 多出來的資料不得變成新行為

- `例子` 新增的列必須仍是同一條 Rule 已經要證明的資料變化，例如規格已允許的其他代碼、同一主張已點名的另一位參與者，或同一計算的另一組輸入與結果。
- 新增的列不得引入來源規格沒有的行為、狀態或拒絕原因。
- 步驟或預期結果已經是另一個主張時，不得為了湊成 `場景大綱` 把該主張放進同一張 `例子`。

## Good Example

- 兩組可配送地區換的是運費，預期仍是商品金額加運費，沒有改成拒絕結帳。

```gherkin
      例子:
        | 配送地區 | 商品金額 | 運費 | 應付金額 |
        | 台北市 | 1000 | 80 | 1080 |
        | 高雄市 | 1000 | 150 | 1150 |
```

## Bad Example

- 為了多一列資料，把「不可配送必須拒絕」塞進原本只證明運費的大綱。

```gherkin
      例子:
        | 配送地區 | 商品金額 | 運費 | 應付金額 | 狀態碼 |
        | 台北市 | 1000 | 80 | 1080 | 201 |
        | 連江縣 | 1000 | 0 | 0 | 409 |
```
