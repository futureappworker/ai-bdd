# 後端句型

## 參數約定

句中的字串參數用雙引號。句中的整數參數不加引號。Data Table 儲存格不加引號。

- **{會員}**：字串。會員名稱，不是會員 ID。示範用會員A。
- **{商品編號}**：字串。可以含前導零，例如 SKU-0042。不是整數。
- **{優惠代碼}**：字串。SAVE80、SAVE10、NONE、EXPIRED。
- **{配送地區}**：字串。台北市、高雄市、未選擇、連江縣。
- **{付款方式}**：字串。信用卡、貨到付款、轉帳。
- **{訂單階段}**：字串。尚未建立、待付款、已付款。尚未建立表示沒有訂單列。待付款對 `pending_payment`。已付款對 `paid`。
- **{庫存}**、**{數量}**、**{件數}**、**{筆數}**、**{單價}**、**{商品金額}**、**{折抵}**、**{運費}**、**{應付金額}**、**{金額}**、**{狀態碼}**：整數。

目錄商品與優惠在建立應用時寫入，購物車與訂單是空的：

| 商品編號 | 單價 | 庫存 |
| --- | --- | --- |
| SKU-1001 | 500 | 10 |
| SKU-1002 | 300 | 5 |
| SKU-0042 | 120 | 8 |

| 優惠代碼 | 門檻 | 折抵 |
| --- | --- | --- |
| SAVE80 | 1000 | 80 |
| SAVE10 | 100 | 10 |

NONE 與 EXPIRED 不在優惠表。台北市運費 80。高雄市運費 150。連江縣不在可配送表。未選擇在計算運費前就拒絕。

## 測試執行約定

- 用 supertest 打每個場景自己的 in-process app。
- 場景世界有 `app`、`db`、`sessions`、`responses`、`last_response`、`cartId`、`orderId`。`sessions` 的 key 是會員名稱，值含 `memberId` 與 `accessToken`。
- 只有「商店沒有進行中的購物車與訂單」可以建立 `app` 與 `db`。已存在就讓這一步失敗。
- 每個會發請求的步驟把回應寫入 `responses[會員]` 與 `last_response`。失敗回應也寫入。
- `sessions` 只由「{會員} 已登入」寫入。When 讀不到 `sessions[會員]` 就失敗，不在 When 裡呼叫 `POST /v1/sessions`。
- Header 固定是 `Authorization: Bearer ${sessions[會員].accessToken}`。body 用 JSON `.send()`。
- 會改狀態的請求送出前記下 `beforeCounts`：`cart_items`、`orders` 的列數，該商品 `products.stock`，該購物車各列數量，以及已有訂單的 `phase`、`goods_amount`、`discount`、`shipping_fee`、`payable_amount`。

## 通道

- **呈現結果**：這次 API 回應裡，句子點名的那一件事。
- **權威狀態**：直接讀這個場景的 `db`。商品看 `products`，購物車看 `carts` 與 `cart_items`，優惠看 `coupons` 與購物車的 `coupon_code`，訂單看 `orders`。
- **再讀確認**：用該會員的 token 再 GET。購物車是 `GET /v1/cart`。訂單是 `GET /v1/orders/{orderId}`；還沒有 orderId 時改 `GET /v1/orders?cartId=`。結果放在 `reread`，不覆蓋 `responses[會員]`。
- **跨視角**：不適用。這個示範每個場景只有會員A。
- **不該發生**：不該多出的列沒有出現，不該改的庫存、數量、金額與階段維持 `beforeCounts`。

When 只負責做出動作並回寫，不斷言，也不填這五個通道。

| "{會員}" 以配送地區 "{配送地區}" 結帳 | • 會員：字串<br>• 配送地區：字串 | 不支援。 | 無 | • 技術入口：`POST /v1/checkout`<br>• 參數映射：配送地區 -> body.region<br>• 上下文來源：會員 -> sessions[會員]；cartId -> 已回寫的 cartId。cartId 還沒有時用這個會員目前的購物車<br>• 回寫資料：responses[會員]、last_response。body 有 orderId 時寫回 orderId。不斷言 status |
| "{會員}" 以 "{付款方式}" 支付 {金額} 元 | • 會員：字串<br>• 付款方式：字串<br>• 金額：整數 | 不支援。 | 無 | • 技術入口：`POST /v1/orders/{orderId}/pay`<br>• 參數映射：付款方式 -> body.method；金額 -> body.amount<br>• 上下文來源：會員 -> sessions[會員]；orderId -> 已回寫的 orderId<br>• 回寫資料：responses[會員]、last_response。不斷言 status |
| "{會員}" 查看訂單 | • 會員：字串 | 不支援。 | 無 | • 技術入口：`GET /v1/orders/{orderId}`<br>• 參數映射：無<br>• 上下文來源：會員 -> sessions[會員]；orderId -> 已回寫的 orderId<br>• 回寫資料：responses[會員]、last_response。不斷言 status |

與 When 文字相同的假設，沿用上面的 When 句型，不另建一列。

## Given 句型

| Given 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 測試撰寫語意 |
