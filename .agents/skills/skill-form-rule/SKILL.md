# SOP

## Phase 1: 撰寫規則

1. Read [Rule File 格式規範](rules/RuleFile-格式規範.md)並取得 Rule File 的結構要求。
2. Write 依需求與已載入規範撰寫或修改目標 Rule File。

## Phase 2: 檢查規則

1. Read 依已載入規範逐條檢查目標 Rule File 並列出不符合項目。

## Phase 3: 修正規則

1. Write 修正目標 Rule File 中全部不符合項目。
