# SOP

## Phase 1: 撰寫 Template

1. Read [Template 格式規範](rules/Template格式規範.md)並取得骨架與範例的撰寫要求。
2. Write 依需求與已載入規範建立或修改目標 Skill `templates/` 目錄下的骨架與範例檔案。

## Phase 2: 檢查 Template

1. Read 依已載入規範檢查目標骨架與範例檔案並列出不符合項目。

## Phase 3: 修正 Template

1. Write 依已載入規範修正目標骨架與範例檔案中的全部不符合項目。
