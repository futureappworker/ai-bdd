# Rule 1 - 通過且憲法允許才打勾

- 處置是通過，且憲法 Rule 沒有停止寫入 `tasks.md` 時，必須把該任務 checkbox 從 `[ ]` 改成 `[X]`。
- 憲法 Rule 要求停止寫入 `tasks.md` 時，不得更新 checkbox，並必須把拒絕原因寫入回覆。
- 打勾只能改本次目標任務那一行。
- 不得新增、修改或刪除 `**Checkpoint**` 與 `**Checkpoint status**` 行。

## Good Example

- T019 已通過，憲法沒有停止寫入，因此只把 T019 改成已完成。

```markdown
- [X] T019 [US1] 在 backend/src/game/one-a-two-b.ts 實作 scoreGuess
- [ ] T020 [US1] 在 backend/src/game/room-state-machine.ts 實作 submit_guess
```

## Bad Example

- T019 通過後，連同尚未驗證的 T020 一起打勾。

```markdown
- [X] T019 [US1] 在 backend/src/game/one-a-two-b.ts 實作 scoreGuess
- [X] T020 [US1] 在 backend/src/game/room-state-machine.ts 實作 submit_guess
```

# Rule 2 - 勾選檢查必須對照憲法決定

- 憲法 Rule 要求停止寫入 `tasks.md` 時，checkbox 維持 `[ ]` 是符合狀態。
- 憲法 Rule 沒有停止寫入，且處置是通過時，checkbox 為 `[X]` 才是符合狀態。
- 不符合狀態必須改回上述符合狀態。
- 修正勾選時不得改動本次目標任務以外的行。

## Good Example

- 憲法沒有停止寫入且 T019 已通過，檢查發現仍是未完成，因此改成已完成。

```markdown
檢查前：
- [ ] T019 [US1] 在 backend/src/game/one-a-two-b.ts 實作 scoreGuess
不符合：T019 應為 [X]
檢查後：
- [X] T019 [US1] 在 backend/src/game/one-a-two-b.ts 實作 scoreGuess
```

## Bad Example

- 憲法已停止寫入，檢查卻把 T019 改成已完成。

```markdown
憲法 Rule：停止寫入 tasks.md
檢查前：
- [ ] T019 [US1] 在 backend/src/game/one-a-two-b.ts 實作 scoreGuess
檢查後：
- [X] T019 [US1] 在 backend/src/game/one-a-two-b.ts 實作 scoreGuess
```
